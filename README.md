# Agro Sim Economy

Учебная игра по экономике предприятия. За четыре сезона ты принимаешь 16 решений о посеве, уборке, продаже зерна, займах и вложениях. После каждого решения игра объясняет последствия. В отчётах можно сверить прибыль, себестоимость и баланс.

## Как запустить

Установи Node.js 22 или новее и выполни команды из папки репозитория.

```sh
npm ci
npm run build
npm test
```

Открой `dist/index.html` в браузере. Сервер для игры не нужен. Прохождение хранится в открытой вкладке до её закрытия или перезагрузки.

## Как предложить улучшение

- Открой Issue и укажи сезон, решение и уровень сложности, если они важны для предложения. Для ошибки приложи шаги воспроизведения и опиши, какой результат ожидал.
- Для пул-реквеста сделай форк, внеси правку и запусти сборку и тест. В описании укажи, что меняется для игрока и как проверить.
- Используй вымышленные названия хозяйств и примеры.

Движок, сценарий, учебные пояснения и компоненты интерфейса находятся в `game/src/game`. Эталонное прохождение и тесты помогают сверять экономику при изменениях.
